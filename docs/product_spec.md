# Kassandra: продукт и ограничения

Объект — один банковский счёт, дата `as_of` означает конец дня, горизонт строго 30 следующих календарных дней. Источник — синтетический архив, последняя доступная дата показывается явно. Счёт не равен всей ликвидности бизнеса. Платёжных поручений и банковской/1С API-интеграции нет.

Путь: импорт CSV → качество и категории → исторический срез → прогноз → реестр событий → замещение ожидания → сценарий → сохранённый план-факт. Факт, регулярное предположение, подтверждённый реестр и сценарий имеют разные подписи.

Деньги — целые копейки. Остаток EOD дня берётся один раз. Несверка не исправляется фиктивным потоком. Сходные операции с разными ID сохраняются. Историческая доступность записи к концу operation_date — допущение, поскольку архив не содержит времени публикации.

SQLite принадлежит сервису/API. Dash вызывает API. ML и финансовая библиотека независимы от Dash/HTTP/LLM. Обучение выполняется командой; запрос применяет артефакт. LLM не нужна для основного пути: прогноз и цифры считает сервис.

Авторизация: локальный режим demo обслуживает только счета, помеченные демонстрационными; личные импорты требуют Bearer principal. Закрытый режим использует конфигурацию пользователей и прав; Dash защищается паролем. Это прототип, не промышленный IAM.
